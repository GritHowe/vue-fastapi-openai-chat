# AI 问答机器人

基于 Vue3 + FastAPI + OpenAI 的 AI 聊天应用。

## 技术栈
- 前端：Vue 3 + Vite
- 后端：Python FastAPI
- AI：OpenAI API / 通义千问

## 快速启动

### 后端
cd backend
pip install -r requirements.txt
cp .env.example .env  # 编辑 .env 填入 API Key
python main.py

### 前端
cd frontend
npm install
npm run dev
